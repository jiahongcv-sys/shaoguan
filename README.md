# 项目骨架

本仓库已包含两个基础框架：

1. `wechat-miniprogram/`：微信小程序基础脚手架。
2. `springboot4/`：Spring Boot 4.0 基础后端脚手架。

## 快速开始

### 微信小程序

1. 打开微信开发者工具。
2. 导入 `wechat-miniprogram/` 目录。
3. 使用测试 AppID（`touristappid`）或替换为自己的 AppID。

### Spring Boot 4.0

```bash
cd springboot4
mvn spring-boot:run
```

默认启动后访问：`http://localhost:8080/api/health`
